# Конвертер валют

Python-приложение для получения актуальных курсов валют и конвертации сумм между валютами.

## Возможности

- Получение актуальных курсов валют через API (open.er-api.com)
- Кэширование данных в JSON-файл (обновление раз в 24 часа)
- Конвертация сумм между любыми валютами
- Валидация кодов валют
- Поддержка более 160 валют
- Обработка сетевых ошибок
- Проверка соответствия базовой валюты в кэше

## Структура проекта

```
├── api_client.py        # HTTP-запросы к API и конвертация валют
├── storage.py           # Работа с файлами (сохранение/чтение JSON, проверка кэша)
├── currency.py          # Базовая версия: получение и вывод курсов
├── cli.py               # Расширенная версия: конвертер сумм с валидацией
├── currency_rates.json  # Кэш данных о курсах валют
└── requirements.txt     # Зависимости проекта
```

## Установка

1. Создайте виртуальное окружение:
```bash
python -m venv venv
```

2. Активируйте его:
```bash
# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование

### Базовая версия

Запуск базовой версии для получения курсов валют:

```bash
python currency.py
```

Программа запросит базовую валюту (например, USD) и выведет курсы для USD, RUB, EUR, GBP.

### Расширенная версия

Запуск версии с конвертером:

```bash
python cli.py
```

Программа запросит базовую валюту и выведет курсы валют:
- Введите базовую валюту (например, USD)
- Введите код исходной валюты для конвертации
- Введите код целевой валюты
- Введите сумму для конвертации

## Кэширование

Данные о курсах валют сохраняются в файл `currency_rates.json`. При повторном запуске программа:
- Проверяет актуальность кэша (файл моложе 24 часов)
- Сравнивает базовую валюту в кэше с запрошенной
- Если кэш свежий и базовая валюта совпадает — использует кэшированные данные
- Если базовая валюта отличается — обновляет кэш

Это снижает нагрузку на API и ускоряет работу приложения.

## Обработка ошибок

Программа обрабатывает сетевые ошибки при подключении к API. При проблемах с интернетом или недоступности API выводится понятное сообщение пользователю.

## API

Проект использует бесплатный API от Exchange Rate API:
- Документация: https://www.exchangerate-api.com/docs
- Endpoint: `https://open.er-api.com/v6/latest/{currency_code}`
- Не требует API-ключа для базового использования
